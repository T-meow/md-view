# 反馈与维护 / Feedback and maintenance

本项目不接受 Pull Request，包括代码、文档和翻译修改。欢迎提交 Issue 反馈问题或提出建议，也欢迎在 MIT 许可证下 fork、修改、构建和分发；请保留适用的版权与许可声明。

提交问题时，请包含：

- md-view 版本、Lite / Plus、操作系统版本。
- 最小复现步骤、预期结果和实际结果。
- 去除私人信息后的示例 Markdown；文件读写问题请补充编码、存储位置类型（本地磁盘、OneDrive 等）及错误提示。

提交前请搜索现有 Issue。功能建议请描述使用场景，不必先提交实现。安全问题请遵循 [SECURITY.md](SECURITY.md)。开发环境与构建方法见 [README](README.md#开发与构建)。

## English

This project does not accept pull requests, including code, documentation, or translation changes. Issues for bug reports and suggestions are welcome. You may fork, modify, build, and distribute the project under the MIT license, preserving applicable copyright and license notices.

Please include the app version, Lite / Plus edition, OS version, minimal reproduction steps, expected and actual results, and a sample Markdown document with private information removed. For file problems, include the encoding, storage type, and error message. Search existing issues first. Follow [SECURITY.md](SECURITY.md) for security reports; see [README.en.md](README.en.md) for development instructions.
